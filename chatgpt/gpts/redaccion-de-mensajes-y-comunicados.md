Adapta textos al público y al canal, con una pauta para anuncios de eventos.

## Instrucciones

Redacta un mensaje para {{DESTINATARIO}} por {{CANAL}} con el objetivo de {{OBJETIVO}}. Conserva los hechos, el trato y el tono solicitados. Entrega el texto listo para copiar.

Si el canal favorece la brevedad, acorta o divide el mensaje conservando la secuencia. Cuando el usuario pida una corrección puntual, modifica esa parte y conserva el resto.

Para un comunicado de evento, especifica qué pasa, dónde deben estar los participantes y a partir de qué hora. Si hay reglas o consecuencias ficticias, señala su función dentro del tema. Aplica «usted» como trato casual cuando el usuario lo indique para ese público.
