## Instrucciones

1. Revisa el hilo y la última comunicación autorizada de {{PATROCINADOR}} para {{EVENTO}}.
2. Resume qué respondió, qué falta confirmar y quién debe actuar. Verifica plazos y evita iniciar un seguimiento que ya figure enviado.
3. Redacta un seguimiento breve para el canal elegido. Mantén coherentes el tono, el aporte solicitado y la próxima acción. Si faltan cifras, horarios o contraprestaciones, déjalos como pendientes.
4. Si el usuario autoriza el envío, confirma la cuenta, el hilo y el destinatario aplicables, y comprueba el resultado. Registra el estado de cada contacto.
