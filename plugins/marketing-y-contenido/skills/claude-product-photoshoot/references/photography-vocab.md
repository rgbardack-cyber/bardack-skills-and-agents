# Vocabulario de fotografía de producto

**Luz**
- Softbox grande lateral (key suave), reflector de relleno blanco, rim light de contorno, contraluz para translúcidos (bebidas, vidrio).
- Hora dorada (cálida, lateral), sombra abierta (neutra), luz dura de mediodía (alto contraste, estilo editorial).
- Sombra de contacto: elipse oscura difusa justo bajo el producto + sombra proyectada más suave.

**Cámara**
- 3/4 elevado (catálogo), frontal a la altura del ojo (héroe), cenital/flat lay (props alrededor), macro/detalle (textura, etiqueta).
- Lentes: 50 mm natural, 85 mm retrato/compresión, 100 mm macro. Profundidad de campo corta para lifestyle, larga para catálogo.

**Fondos**
- Seamless sólido/degradado, mármol, madera clara, microcemento, papel de color, vidrio/acrílico con reflejo.
- Estilos: clean girl, cottagecore, quiet luxury, dark academia, Y2K, minimal nórdico.

**Composición**
- Regla de tercios, espacio negativo para texto, producto 40–60 % del encuadre en hero, diagonal para dinamismo, repetición (3 unidades) para escala.

**Conceptual**
- Levitación (sombra desplazada), splash (congelado), apilado escultural, reflejo en espejo, escala exagerada.

**Prendas/try-on**
- Encuadres: cuerpo entero, 3/4, cintura arriba, detalle. Entornos: estudio, calle, interior cálido, editorial.

**Anti-patrones**
- Producto deformado, etiqueta ilegible, sombras que no coinciden con la luz, demasiados props, texto sobre la zona clave.
